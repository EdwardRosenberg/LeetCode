# LeetCode Prep

A browsable review guide for interview prep, organized by algorithm pattern. Each pattern below links to an index of solved problems, cues, and write-ups.

| Pattern | Recognition cue |
|---------|------------------|
| [Arrays & Hashing](src/main/java/arraysandhashing/README.md) | fast lookups, frequency counts, or grouping-by-signature — anything a HashMap/HashSet turns from O(n²) into O(n) |
| [Sliding Window](src/main/java/slidingwindow/README.md) | growing/shrinking a contiguous window to satisfy a size, sum, or uniqueness condition |

More patterns (`twopointers`, `stack`, `binarysearch`, `linkedlist`, `trees`, `heap`, `graphs`, `intervals`, `dp`) will get a row here as their first solution is indexed.
